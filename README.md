# Mattermost Calls Install Scripts

Bash scripts for installing [Mattermost Calls](https://docs.mattermost.com/channels/make-calls.html) infrastructure components as Linux systemd services. Supports both internet-connected and air-gapped environments.

## Scripts

| Script | Purpose |
|--------|---------|
| `install-rtcd.sh` | Install [rtcd](https://github.com/mattermost/rtcd) (real-time communication daemon) |
| `install-offloader.sh` | Install [calls-offloader](https://github.com/mattermost/calls-offloader) (recording/transcription job service) |
| `setup-airgap-offloader.sh` | Prepare a transfer bundle for air-gapped deployment (run on internet-connected machine) |
| `deploy-airgap-offloader.sh` | Deploy calls-offloader in an air-gapped environment (generated by `setup-airgap-offloader.sh`) |

## Requirements

- Linux with systemd
- Root/sudo access
- `wget` or `curl` (for online installs)
- Docker (for calls-offloader — it runs recorder/transcriber as containers)

## Quick Start

### Install rtcd

```bash
# Online — downloads the binary from GitHub
sudo ./install-rtcd.sh

# Air-gapped — use a pre-downloaded binary
sudo ./install-rtcd.sh ./rtcd-linux-amd64 --checksum ./rtcd-checksums.txt
```

The script creates a `rtcd` system user, installs the binary to `/opt/rtcd/`, writes a default config, and starts the service.

### Install calls-offloader

```bash
# Online — downloads the binary from GitHub
sudo ./install-offloader.sh --version v0.9.4

# With a custom image registry (e.g. for air-gapped)
sudo ./install-offloader.sh --binary ./calls-offloader-linux-amd64 \
    --image-registry localhost:5000/mattermost
```

The script creates a `mattermost` system user (added to the `docker` group), installs the binary to `/usr/local/bin/`, configures a systemd service with environment-based settings, and starts the service.

### Air-Gapped Deployment

Air-gapped deployment is a two-phase process:

**Phase 1 — Prepare the bundle** (on an internet-connected machine with Docker):

```bash
./setup-airgap-offloader.sh \
    --recorder v0.8.8 \
    --transcriber v0.7.1 \
    --offloader v0.9.4
```

This pulls Docker images, downloads the offloader binary, saves everything to archives, and generates `deploy-airgap-offloader.sh`.

**Phase 2 — Deploy** (on the air-gapped machine):

Transfer the generated files, then run:

```bash
sudo ./deploy-airgap-offloader.sh
```

This loads the Docker images, starts a local registry on port 5000, pushes the images into it, and runs `install-offloader.sh` pointed at the local registry.

## Default Ports

| Component | Port | Protocol | Purpose |
|-----------|------|----------|---------|
| rtcd | 8045 | TCP | API |
| rtcd | 8443 | UDP+TCP | WebRTC/ICE media |
| calls-offloader | 4545 | TCP | API |
| Local Docker registry | 5000 | TCP | Air-gapped image hosting |

## Install Locations

| Component | Binary | Config | Logs | Service User |
|-----------|--------|--------|------|-------------|
| rtcd | `/opt/rtcd/rtcd` | `/opt/rtcd/config/config.toml` | `/opt/rtcd/logs/` | `rtcd` |
| calls-offloader | `/usr/local/bin/calls-offloader` | systemd environment vars | `/var/log/calls-offloader/` | `mattermost` |

## Post-Install

After installing, configure the Mattermost Calls plugin to point at the new services:

- **rtcd**: Set the `rtcd service URL` in the Calls plugin settings to `http://<rtcd-host>:8045`
- **calls-offloader**: Set the `Job service URL` to `http://<offloader-host>:4545`

### Useful Commands

```bash
# rtcd
systemctl status rtcd
journalctl -u rtcd -f
curl http://localhost:8045/version

# calls-offloader
systemctl status calls-offloader
journalctl -u calls-offloader -f
curl http://localhost:4545/version
```

## Finding Compatible Versions

To find the correct recorder/transcriber versions for your Calls plugin:

1. Check your Calls plugin version in **System Console > Plugins > Plugin Management**
2. Look at [`plugin.json`](https://github.com/mattermost/mattermost-plugin-calls/blob/main/plugin.json) at that version tag
3. Find the `calls_recorder_version` and `calls_transcriber_version` fields
